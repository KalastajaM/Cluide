# _archive

Superseded material, kept for reference and excluded from routine reads. Moving a file here is the project's
alternative to deleting it: the decision to actually delete gets made later, deliberately, with
the file in front of you.

Two rules make the folder work:

- **Read only for named, authorised recovery or provenance work.** A stale version in context is worse than an absent one — it contradicts
  the current material without announcing that it is out of date. Load only the required item, label its date/status, and never
  silently promote it back to the current source of truth. `AGENTS.md` defines this boundary.
- **Nothing arrives here new.** Only material that was live somewhere else in the project.

One archive folder is enough for most projects. Guide 24 (`24_PROJECT_FOLDER_STRUCTURE.md`) has
the rule for when it is not.
