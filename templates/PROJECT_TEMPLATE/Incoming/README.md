# Incoming

Drop new material here when it reaches this project outside a chat: scans, downloads,
photos, email exports, files someone else hands you. Claude files it from here into the
project's proper homes.

**Delete this folder if the project only ever receives material through chat** — an intake
folder that nothing lands in is clutter, and one nobody has told Claude to check just
fills up. See Guide 24 (`24_PROJECT_FOLDER_STRUCTURE.md`) for the full pattern.

## Rules

- **Emptied, not managed.** Nothing lives here. Anything still present after a filing
  pass is either a question waiting for you or a file Claude could not identify.
- **Filed by content, not filename.** Claude opens the file, works out what it is, and
  renames it to this project's convention on the way in.
- **Destinations are proposed before anything moves**, unless `CLAUDE.md` says otherwise.
  These are your documents; a wrong destination is expensive to notice later.
- **Nothing is deleted from here.** Material that does not belong goes to the archive.
